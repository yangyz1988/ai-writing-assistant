# 会员与支付安全边界

## 当前保证

- 扩展包只包含 6 个免费模板的完整提示词；24 个 Pro 模板仅包含名称、图标和 ID。
- 浏览器本地存储不能解锁 Pro。付费权益必须由会员 API 根据短期访问令牌返回。
- 会员 API 生产地址必须使用 HTTPS；仅允许 localhost/127.0.0.1 在本地开发时使用 HTTP。
- 收银台地址必须由服务端生成，并且客户端只接受 HTTPS URL。
- 客户端不接收价格金额；服务端根据 `plan + billing_cycle` 从服务端价格表选择商品，避免篡改金额。
- 客户端错误不包含令牌、支付详情、堆栈或上游错误正文。

## 服务端必须实现

1. 所有接口验证访问令牌和资源所有权。
2. 登录、会员读取和支付会话分别按 IP、账户和设备限流。
3. 支付回调验证签名、金额、币种、订单归属和事件时间，并以事件 ID 保证幂等。
4. 会员状态只能由已验证的支付回调或管理员审计操作修改。
5. AI 网关根据服务端模板 ID 执行 Pro 提示词，不能把完整 Pro 提示词返回扩展。
6. 日志仅记录用户 ID、订单 ID、模板 ID、耗时和状态；不记录访问令牌、完整正文或支付凭据。
7. CORS 仅允许正式扩展 ID 和官网来源；生产环境拒绝通配来源。
