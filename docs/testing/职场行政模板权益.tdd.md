# 职场行政模板权益：TDD 证据

## 用户旅程

- 作为免费用户，我只能使用 6 个职场行政试用模板，避免误用付费能力。
- 作为 Pro 用户，我可以使用全部 30 个职场行政模板。
- 作为系统，未知或缺失的会员状态必须按免费用户处理，避免意外开放 Pro 功能。
- 作为免费用户，我可以看到当前套餐、Pro 价格和锁定模板清单，但不能读取锁定模板的提示词内容。

## 已知范围

- 当前会员状态由 `chrome.storage.local.membershipPlan` 提供，默认为 `free`；后续账号服务应由后端签发并同步该状态。
- 当前切片不包含支付、登录或服务端权益校验；这些能力不能由浏览器本地存储作为最终授权依据。
- 项目此前没有覆盖率配置，未执行覆盖率阈值检查。
- 应用内浏览器技能路径不可用，仓库也未安装 Playwright；本轮完成静态 React 渲染测试，尚未执行真实 Chrome Popup 截图验证。
