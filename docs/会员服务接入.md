# 会员服务接入

账户页默认显示“会员服务尚未配置”，不会向占位域名发送请求。部署会员 API 后，通过构建环境变量启用：

```powershell
$env:MEMBERSHIP_API_BASE_URL='https://membership.example.com'
npm run build
```

构建会同时把 API 地址注入扩展代码，并向生成的 `dist/manifest.json` 添加对应的最小主机权限。生产地址必须使用 HTTPS；本地开发允许 `http://localhost` 或 `http://127.0.0.1`。

登录成功后的访问令牌只写入 `chrome.storage.session`，关闭浏览器会话或令牌过期后失效，不进入 `storage.local` 或 `storage.sync`。

服务端需实现 [会员 OpenAPI 契约](api/membership.openapi.yaml)，至少包括：

- `POST /api/v1/auth/email-codes`
- `POST /api/v1/auth/email-sessions`
- `GET /api/v1/membership`

验证码发送接口应对已注册和未注册邮箱返回相同响应，避免泄露账户是否存在。
