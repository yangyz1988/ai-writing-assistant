## 推荐：DeepSeek

**优势**:
- API 格式完全兼容 OpenAI
- 价格极低（1元/百万tokens）
- 中文效果优秀
- 无需修改太多代码

**获取 API Key**:
1. 访问 https://platform.deepseek.com/
2. 注册账号（手机号或邮箱）
3. 进入 API Keys 页面
4. 创建新的 API Key
5. 复制 Key（格式类似: sk-...）

**使用方法**:
- Provider: 选择 "DeepSeek"
- API Key: 输入你的 DeepSeek Key
- Model: 输入 "deepseek-chat"
- Base URL: 自动设置为 https://api.deepseek.com
